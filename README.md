# Student portfolio site

A small, responsive portfolio built with plain HTML, CSS, and JavaScript. No framework or install step is needed.

## Open the site

1. Open `index.html` in a browser.
2. Scroll through the page to review the sections.
3. Catch any of the falling stars, drag it in any direction, and release to throw it. Stars use cool blue, violet, cyan, and soft pink gradients; each keeps the velocity from your drag and leaves the screen.

## Personalize it before publishing

Open `index.html` in a text editor and search for these placeholders:

- Replace `Your Name` with your name.
- Change the `YN` initials in the header and footer to match your name.
- Replace `YOUR_EMAIL@example.com` with your email address in the `mailto:` link.
- Update any wording that doesn’t accurately reflect your work or current course status.

The page currently includes the facts you shared: VIT Vellore CSE, expected graduation in July 2030, Harvard CS50, NSEC and IOQM qualification in 2025, club memberships, Hackulus, SmartSplit AI, and your database contribution to a professional networking app. Review these details before publishing.

## Files

- `index.html` contains the page content and sections.
- `styles.css` controls colors, typography, layout, and mobile styling.
- `script.js` draws the starfield and lets visitors drag and toss stars.

To change the star appearance or motion, edit the colors and star settings near the top of `script.js`. The page respects the visitor’s reduced-motion preference.

## Publish

This is a static site, so it can be deployed on a static hosting service such as GitHub Pages or Netlify. Upload the three site files together; keep their filenames and relative locations unchanged.
